# Debrid Hub

Aggregate direct download links across debrid services (Real-Debrid, AllDebrid, TorBox) for JDownloader2 — CLI, REST API, and web UI from a single package.

The app lives in **[`debrid-hub/`](debrid-hub/)** — see **[debrid-hub/README.md](debrid-hub/README.md)** for install, quick start, configuring keys, the CLI, and the REST API.
