Provider API keys

Stored encrypted on the server. Leave a field blank to keep the current key; use Remove to clear a stored one. A key set here overrides the matching environment variable. If a key was added to the encrypted store another way (e.g. debrid-hub config set via docker compose exec, or a pre-encrypted file placed in the mounted data directory) hit Load to pick it up without restarting.

Provider requests / responses

Raw outbound calls from the last refresh. Secret-looking params (API keys, tokens) are redacted before this ever reaches the browser.

Extensions

Stremio-protocol addon manifest URLs power the Discover tab (browse, search, cast/posters, and sources to add straight to your debrid account). URLs often carry a personal config token — stored encrypted on the server, same as provider keys, and never shown again once added.
